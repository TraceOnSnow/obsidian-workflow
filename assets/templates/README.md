# 记录模板

模板只提供新稿的起点；已有笔记沿原文修改，不整份套用。Obsidian原生模板会把 `{{title}}` 换成文件名，直接复制时自行替换标题。

- [[templates/笔试复盘|笔试复盘]]：一场一篇，逐题先写题目大意（输入输出、要求和数据范围，让没做过的人也能读懂），再写思路与解法、必要代码；当时思路与正解一致时合并。
- [[templates/面试复盘|面试复盘]]：一场一篇，逐题写问题与回答；有必要时区分现场回答和事后参考解答，不保留空栏。
- [[templates/作品记录|作品记录]]：只用于已有作品的实质感想，沿用总表行的身份；日常字段仍在总表维护。

模板不预填稳定身份，不追溯改写旧笔记。邀约和结果只更新追踪。技术回答直接讲结论和原理，默认不加辅导口吻或外部参考链接。具体规则见[[config/整理与发表规约|整理与发表规约]]，操作见[[使用说明]]。

模板的维护来源与安装副本由维护工具比较；直接编辑模板时保留你的修改，发生差异先合并，不用重新安装覆盖。模板目录是否已在本机配置，应在Obsidian原生模板设置中确认。
