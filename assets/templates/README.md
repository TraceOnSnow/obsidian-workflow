# 记录模板

模板只提供新稿的起点；已有笔记沿原文修改，不整份套用。Obsidian原生模板会把 `{{title}}` 换成文件名，直接复制时自行替换标题。

- [[templates/笔试复盘|笔试复盘]]：一场一篇，逐题先写题目大意（输入输出、要求和数据范围，让没做过的人也能读懂），再写“我的思路”“思路分析”和代码；当时思路与正解一致时合并。
- [[templates/面试复盘|面试复盘]]：原则上一场一篇，逐题写问题与回答；标题写“一面面经”“二面面经”或“AI面面经”，不用“人工面经”；本人确认的合集分场次写。每题先写本人回答，需要时接“参考解答”，不保留空栏。正文只写事情本身，不加“未核实”“材料没有留下”这类说明句。
- [[templates/作品记录|作品记录]]：用于本人对已有作品的感想，长短不限，沿用总表行的身份；日常字段仍在总表维护。
- [[templates/每日笔记|每日笔记]]：Obsidian原生“日记”按日期新建时套用。“日程与待办”嵌入TaskNotes的当日视图，任务本身存在 `TaskNotes/Tasks/`，不在这里手抄；“时间”留给程序填统计数字；“记录”只由本人写当天短记，细节仍归专题。

模板不预填稳定身份，不追溯改写旧笔记。邀约和结果只更新追踪。技术回答直接讲结论和原理，默认不加辅导口吻或外部参考链接。具体规则见[[config/整理与发表规约|整理与发表规约]]，操作见[[使用说明]]。

模板的维护来源与安装副本由维护工具比较；直接编辑模板时保留你的修改，发生差异先合并，不用重新安装覆盖。模板目录是否已在本机配置，应在Obsidian原生模板设置中确认。
