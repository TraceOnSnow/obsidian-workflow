# 记录模板

模板提供最少的写作结构，按实际材料增删栏目，不要求每一栏填满。

| 模板 | 适用内容 |
| --- | --- |
| `作品记录.md` | 有实质感想的作品正文；评分、进度与体验日期在作品总表维护 |
| `笔试复盘.md` | 按题组织题意、当时思路、事后解法和代码 |
| `面试复盘.md` | 按实际问题组织当时回答与参考补充 |

只记录邀请、安排或结果时，更新已有追踪记录即可，不创建空白复盘。有实质题目或作答时再维护对应正文。模板中的标题、日期、公司与角色是待填字段，不表示已经发生。

整理时保留已有代码和必要细节，区分现场回答、事后解法与 AI 补充，不把补充答案写成当场答对。没有明确日期或结论时保留未知。

私人原稿保留完整内容。需要公开时准备独立 Post，按当前要求检查匿名化、日期和公开范围；两稿分别修改并保留双向入口。使用模板和保存正文均不会自动发表。
