# 库内常用字段

作品日常字段在 `works/作品总表.md` 的同一行维护；感想列只在有正文时链接独立Markdown。Library `get` 返回完整逻辑Work，保存用原ID `replace`，由程序分开写入总表和感想，不把完整逻辑属性手工复制进感想文件。

| 字段 | 含义 |
| --- | --- |
| id / schema_version | 内容稳定身份与工具格式；总表行与感想复用原Work身份 |
| kind | note普通笔记、work作品、post文章；不通过文件夹猜类型 |
| title / type | 作品标题与媒体类型，在总表维护 |
| rating | 0–100；85就是85分，null未知，0有效；可保留小数，新输入5就是5分 |
| status | planned待体验、in-progress进行中、completed已完成、on-hold暂停、dropped已搁置 |
| note | 可能公开的卡片短评；完整私人感想写关联正文 |
| experiences | 完整体验记录，包含startedOn／endedOn等；总表日期编辑第一段，其他段及行ID保留 |
| related_works | Post自动派生的反向作品导航，不是发布字段 |
| link / locale | 网站文章固定路径与语言，已有值不要随意改 |

评分、进度、短评和开始／结束日期可直接在总表修改，日期不再是只读公式列。新日期按已知年、月、日精度填写，未知留空，不默认填今天；已有历史时间戳保持原值。结束体验不自动等于通关。

slug、别名、标签、封面、发行资料、简介、网站article关联和Steam原始观察由程序按稳定ID维护在隐藏元数据中。缺省不表示清空网站，不补回感想属性或手改隐藏状态。

补写感想复用总表行的原ID，通过Library `get`／`replace`建立文件和链接；新作品才新建记录，不能复制旧ID。服务器 `prepare-work-review` 只在明确要求复制时准备独立Post当前稿及双链，两稿以后分别修改，Post发表另行明确。

目录迁移不自动公开或补发历史差异。后续总表中已有公开卡片的评分、短评、进度和体验改动，会经原同步守卫更新网站；新作品和私密作品不首次公开，不发表关联Post或私人正文。首次公开作品与发表Post仍需明确要求及实际回读；其他正文保存只更新当前稿。
