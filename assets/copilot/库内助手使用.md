# Copilot 库内助手

`personal-library` 用于笔记整理、口述补充、作品总表和独立 Post 关系。技能文件不包含账号或模型，也不自动建立服务器连接。

## 安装与试用

先按所用 Copilot 版本的界面配置 Agent 后端和模型。在支持 Skills 的 Agent Chat 中加载 `personal-library`；具体菜单、后端支持及重新加载方式以当前插件为准。Quick Chat 与 Agent Chat 的能力可能不同，应在本机核实。

项目提供安装预览，需先安装 Python 项目依赖，并指定已初始化的库：

```sh
python scripts/install-copilot-library-skill.py --vault /absolute/path/to/vault
python scripts/install-copilot-library-skill.py --vault /absolute/path/to/vault --apply
```

安装器复制技能、字段说明和指南，已有不同内容会保留并报错。它不会安装 Copilot、配置模型或验证客户端工具调用。请先在临时库试用。

可以尝试：

> /personal-library 整理当前笔记最后两段，保留细节，其他内容不改。

> /personal-library 找到这篇作品感想与独立文章，先核对两边的关系，不发布。

> /personal-library 在作品总表中把我指定的书改为 85 分，保留其他记录和布局。

## 修改与发表

作品日常字段放在总表，实质感想放在关联正文。评分为 0–100，0 有效，空值未知。新建关联感想需要内容库工具时，应通过对应 Work 身份操作；没有工具的客户端不能另造身份替代。

私人原稿与 Post 分开修改。普通保存只更新当前稿，准备 Post 草稿也不表示发表。已有公开作品的日常字段能否自动更新，取决于自己的同步配置与授权。首次公开或文章发表，需要明确请求并调用可用的发布工具；实际 API 和前台回读完成后才确认上线。

完成一次试用时检查：技能是否可见、模型能否调用需要的工具、实际差异是否符合请求、文件是否保存，以及撤销和恢复是否可用。服务器静态检查不能代替本机体验。凭据、插件配置与隐藏历史不应作为普通笔记交给助手批量修改。
